# Velora – Social Media Platform 🌸

Velora is a Django-based social media platform developed as a web development project.

## ✨ Features

* User Sign Up
* User Login & Logout
* Create Posts
* Like / Unlike Posts
* Comment on Posts
* User Profiles
* Follow / Unfollow Users
* Followers List
* Following List
* View Other Users' Profiles
* Dynamic User Suggestions
* Responsive and Clean Interface

## 🛠️ Technologies Used

* Python
* Django
* HTML5
* CSS3
* SQLite
* Git & GitHub

## 🚀 How to Run the Project

### 1. Clone the Repository

```bash
git clone https://github.com/malihaaftab372-sys/Velora-Social-Media-Platform.git
cd Velora-Social-Media-Platform
```

### 2. Install Django

```bash
pip install django
```

### 3. Apply Migrations

```bash
python manage.py migrate
```

### 4. Start the Development Server

```bash
python manage.py runserver
```

### 5. Open in Browser

```text
http://127.0.0.1:8000/
```
